# QStar 0.6 Beta Readiness Gate

이 문서는 QStar `0.6.x-beta` public prerelease를 만들기 위한 현재-facing readiness gate다.
0.6 line의 목적은 Stella daemon을 documented beta opt-in 기능으로 유지하되, default build
path와 안정성 약속은 보수적으로 유지하면서 Linux x86_64 beta asset까지 여는 것이다.

```txt
status: 0.6 beta readiness gate
current runtime version: qstar 0.6.1-beta
release line: qstar 0.6.1-beta
baseline date: 2026-06-14
```

## Verdict

QStar는 `0.6.1-beta` public prerelease를 낼 수 있다.

판단:

- macOS arm64와 Linux x86_64 runtime tarball을 public prerelease asset으로 배포한다.
- Makefile은 계속 canonical bootstrap/release build path다.
- QStar self-host graph는 regular beta gate로 유지한다.
- Stella executor는 medium corpus에서 Ninja와 같은 수준의 대표 수치를 가진다.
- Stella daemon은 beta opt-in 기능으로 문서화한다.
- 기본 `qstar build`는 daemon을 쓰지 않는다.
- Linux asset은 Ubuntu release workflow 또는 clean Linux x86_64 host 산출물만 사용한다.
- Windows는 manual native validation candidate이며 official support가 아니다.

## Release Surface

0.6에서 사용자-facing으로 강조할 기능:

- `qstar daemon --socket path --start`
- `qstar daemon --socket path --stop`
- `qstar daemon --socket path --serve`
- `qstar build --use-daemon=auto|always --daemon-socket path`
- `qstar daemon --socket path --query method`
- daemon event streaming과 CMake-style progress output
- in-memory dirty/deps state와 watcher invalidation
- daemon read-only IDE/AI API
- Stella/Ninja/daemon medium performance line protocol

Daemon read API method:

```txt
hello
workspace.info
targets.list
diagnostics.list
compile_commands.path
build.summary
```

Read API는 build/test/clean mutation을 열지 않는다.

## Release Gate

```sh
make all
make check
make qstar-self-host-tests
make qstar-medium-project-readiness-tests
make qstar-public-beta-release-tests
git diff --check
```

Socket 허용 host에서는 다음을 추가로 실행한다.

```sh
QSTAR_TEST_QSTAR=build/bin/qstar sh tests/smoke.sh
QSTAR_TEST_QSTAR=build/bin/qstar sh tests/medium-project-performance.sh
```

## Package

```txt

checksum file: SHA256SUMS
release note: docs/releases/v0.6.1-beta.md
```

The release tarball is generated by:

```sh
make qstar-public-beta-release-tests
```

## Deferred

- Windows official host support and release asset.
- Stable daemon protocol version promise.
- Linux daemon socket/watcher CI lane.
- Windows named pipe daemon.
- Remote daemon access.
- Cale source Ninja wrapper lowering.
- Remote package resolution, registry, and lockfile management.

## Version Policy

Runtime version is owned by `include/qstar/qstar.h`. Git tags must match
`v$QSTAR_VERSION`. VSCode extension version is independent from the runtime and
is not bundled into the public beta runtime tarball.
