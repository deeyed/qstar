# QStar v0.4.0 Beta 1

QStar v0.4.0 Beta 1 is the first public prerelease of QStar as a standalone
build system.

This release is a beta. The macOS arm64 binary is the only published binary
artifact for this prerelease. Linux host validation is underway, Windows host
support is planned, and both will be validated before QStar 1.0.

## Highlights

- Stella native executor is the default build backend.
- Ninja backend is available with `-G ninja`.
- `qstar.group` provides dependency-only aggregate targets.
- `qstar.config` and target `configs = {...}` remove repeated compiler option
  boilerplate.
- `qstar.import_file(...)` and `qstar.import_module(...)` provide explicit,
  traceable authoring reuse.
- `qstar.project.generated_dir` keeps generated artifacts under a chosen output
  root.
- `-B` and `-G` provide CMake-style build directory and backend overrides.
- Compact progress output is enabled by default, with `--progress plain` for
  deterministic log output.
- QStar can now build QStar through its self-host graph for Stella and Ninja
  backend validation.
- Wiki, manpages, docs CLI, LSP, and VSCode grammar support cover `qstar.lua`,
  `.qst`, and `.qsm`.

## Install

```sh
tar -xzf qstar-v0.4.0-beta.1-macos-arm64.tar.gz -C "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
qstar --version
```

Expected version:

```txt
qstar 0.4.0-beta.1
```

## Validate

```sh
qstar init c-app /tmp/qstar-hello
qstar --file /tmp/qstar-hello/qstar.lua build //:app --progress plain
/tmp/qstar-hello/build/qstar/out/___app/app
```

## Platform Status

| Host platform | Status |
| --- | --- |
| macOS arm64 | Beta release artifact |
| Linux | Validation underway |
| Windows | Planned validation |

QStar 1.0 is reserved for validated release artifacts and CI coverage across
macOS, Linux, and Windows.

## Notes

- The Makefile remains QStar's canonical bootstrap and release build path.
- The QStar self-host graph is used as backend parity validation.
- Linux validation is underway; Windows path/process rules are documented as a
  pre-port contract, but no Windows artifact is published in this prerelease.
- The VSCode extension is not included as a release asset in this prerelease.
- QStar is licensed under Apache-2.0. Lua vendor license text is preserved in
  `LICENSE/lua.txt`.
