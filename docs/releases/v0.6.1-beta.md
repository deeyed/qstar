# QStar v0.6.1 Beta

QStar v0.6.1 Beta is a public prerelease for the standalone QStar build system.
This beta patch keeps the Stella daemon as an explicit opt-in workflow and adds
the first Linux x86_64 runtime tarball next to the macOS arm64 artifact.

This release remains a beta. The intended public binary assets are:

```txt
qstar-v0.6.1-beta-macos-arm64.tar.gz
qstar-v0.6.1-beta-linux-x86_64.tar.gz
SHA256SUMS
```

## Release Decision

Runtime version:

```txt
qstar 0.6.1-beta
```

Linux x86_64 is now a beta release artifact, not only a dry-run candidate. The
Linux tarball must be produced by the Ubuntu release workflow or a clean Linux
x86_64 host after source validation, Linux validation, explicit Ninja backend
parity, extracted tarball smoke, and Stella/Ninja medium performance artifact
collection.

Windows remains a manual native validation candidate and has no public asset in
this release.

## Highlights

- Linux x86_64 public beta runtime asset.
- Linux release upload path keeps `SHA256SUMS` merged across macOS and Linux
  assets.
- Linux validation workflow has an opt-in `publish_linux_asset` job that checks
  out the selected tag, rebuilds on Ubuntu, runs the release gates, and uploads
  the Linux tarball.
- Stella daemon remains documented beta opt-in, not default-on.
- Build output keeps CMake-style progress lines and warning/error coloring.
- Ninja backend parity remains part of the Linux asset gate.

## Install

macOS arm64:

```sh
tar -xzf qstar-v0.6.1-beta-macos-arm64.tar.gz -C "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
qstar --version
```

Linux x86_64:

```sh
tar -xzf qstar-v0.6.1-beta-linux-x86_64.tar.gz -C "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
qstar --version
```

Expected version:

```txt
qstar 0.6.1-beta
```

## Release Gates

The local macOS release gates are:

```sh
make all
make check
make qstar-self-host-tests
make qstar-medium-project-readiness-tests
make qstar-public-beta-release-tests
git diff --check
```

The Linux asset gate must run on Ubuntu or a clean Linux x86_64 host:

```sh
make all
make check
make qstar-linux-validation-tests
make qstar-ninja-backend-parity-tests
QSTAR_RELEASE_PLATFORM=linux-x86_64 QSTAR_RELEASE_TAG=v0.6.1-beta \
  tools/package-public-beta.sh
```

The GitHub release upload path is the `Linux Validation` workflow with
`publish_linux_asset=true` and `release_tag=v0.6.1-beta`. It runs
`tools/publish-github-release-asset.sh`, which merges the Linux checksum into
the release `SHA256SUMS` before upload.

After the GitHub release is published, maintainers verify uploaded assets with:

```sh
QSTAR_RELEASE_PLATFORM=macos-arm64 QSTAR_RELEASE_TAG=v0.6.1-beta \
  make qstar-public-beta-download-smoke
QSTAR_RELEASE_PLATFORM=linux-x86_64 QSTAR_RELEASE_TAG=v0.6.1-beta \
  make qstar-public-beta-download-smoke
```

The Linux download smoke must run on Linux.

## Deferred Before v1.0

- Windows public release asset and native release gate.
- Daemon default-on lifecycle policy.
- Stable daemon protocol version promise.
- Broader CI/release matrix across macOS, Linux, and Windows.

The QStar 1.0 milestone remains reserved for validated release artifacts and CI
coverage on all major host platforms.
